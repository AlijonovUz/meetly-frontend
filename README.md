# Meetly Frontend

Meetly — Zamonaviy onlayn video-konferensiya va uchrashuvlar boshqaruvi platformasi.

## Texnologiyalar
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **State Management:** Redux Toolkit
- **WebRTC & Video:** LiveKit Client SDK
- **Real-time:** WebSockets & Django Channels
- **Autentifikatsiya:** Authly SSO (OAuth2 / OpenID Connect)

## O'rnatish va Ishga tushirish

1. Bog'liqliklarni o'rnatish:
```bash
npm install
```

2. `.env` faylini sozlash:
```bash
cp .env-example .env
```

3. Development serverini ishga tushirish:
```bash
npm run dev
```

4. Production uchun yig'ish (build):
```bash
npm run build
```
